**next-minimal-blog** is a starter template for a statically generated blog.
It is built with the same setup you get from the official shadcn/ui getting-started guide,
plus only what a blog needs: MDX for posts and Shiki for code highlighting.

## What's inside

| Area         | Tool                                         |
| ------------ | -------------------------------------------- |
| Framework    | Next.js (App Router, static generation)      |
| UI           | shadcn/ui (Base UI) + Tailwind CSS           |
| Content      | MDX files in `src/content/blog`              |
| Code blocks  | shadcn/ui Code Block + Shiki (at build time) |
| Feed and SEO | RSS, sitemap, and Open Graph metadata        |

## Where things live

```txt title="Project structure"
src/
  app/              # Pages and layouts (App Router)
  components/
    ui/             # shadcn/ui components (generated by the CLI)
    blog/           # Post cards, lists, pagination ...
    mdx/            # How MDX is rendered (code blocks, callouts ...)
  content/blog/     # Your posts live here
  lib/              # Loading posts, tags, utilities
```

## Next steps

1. Edit `src/lib/config.ts` to set your site name and links.
2. Replace the posts in `src/content/blog` with your own.
3. Read the other posts on this site. Each one covers one feature of the template.
